# pdf2md 调参手册

`scripts/pdf2md.py` 不认固定版式，全部靠统计。理解它怎么判断，才知道该调哪个参数。

## 识别流程

1. **抽行**：`pdfplumber` 的 `extract_text_lines()` 给出每行的文字、字号、左右端点、上下沿。
2. **清理**：丢掉页面上下 10% 区域内的页码；丢掉在 ≥25% 页面同一区域重复出现的短行
   （书名页眉、章节页脚）；丢掉 PDF 自带目录：前 10% 页面里出现「目录/Contents」时，
   整页丢弃到第一页出现标题字号为止；带页码或点前导符的目录行再逐行丢弃；
   丢掉落在表格框内的行（表格结构化输出）。
3. **正文号**：按字符数加权，取出现最多的字号（±0.4pt 视为同一字号）。
4. **左边距**：正文行最左端点的中位数。所有缩进都以它为基准。
5. **标题**：所有 ≥ 正文号 × `--heading-scale` 的字号，从大到小依次映射为
   h2、h3、h4……（`--heading-base` 控制起点）。紧邻的下一级短标题会并入上一条
   （「第一章」+「回目」合成一个标题）。
6. **分块**：
   - 等宽字体行 → 代码块（夹在中间的短中文注释行也会并入）
   - 行首 `1.` / `•` / `-` 等标记 → 列表项，折行并回条目
   - 缩进 ≥ `--quote-indent-chars` 个字 → 引文块 `>`；同缩进的后续行继续并入，
     2 字缩进的折行只在上一行顶到右边距时才并入
   - 缩进 ≥ `--indent-chars` 个字 → 新段落
   - 顶格 → 上一段的续行；若与上一行间距 > `--paragraph-gap` × 字号 → 新段落
   - 上一行右端点贴到右边距（1.5 字以内）→ 下一行是折行，直接拼接
7. **输出**：书名 h1 + 重新生成的目录 + 正文块 + 图片。段落之间用空行分隔，
   不写首行缩进；段间留白交给 PDF / 电子书样式。

拼接规则：两侧都是中日韩字符时不加空格；英文按空格拼，行尾连字符会去掉；
中文标点整理会消掉 PDF 对齐造成的字间空格。

### 输出细节

- **引文优先**：缩进达到 `--quote-indent-chars` 的行先判为引文，再考虑“上一行
  顶到右边距 → 折行续接”。否则页面顶部的诗词会被并进上一段。
- **容差 0.5pt**：缩进判断带 0.5pt 容差，避免 `136.99 - 76.99 = 59.999...`
  这类浮点误差把 4 字引文判成 3.99 字。
- **标题空格**：章标题与紧邻的副标题合并时补一个空格（`第一回 回目上句 回目下句`），
  不再直接粘成 `第一回回目上句回目下句`。
- **分隔线**：独立成行的 `***` / `___` / `* * *` 统一输出 `---`。

生成的 Markdown 交付前必须跑 `bash scripts/md-lint.sh book.md`，顺序是：

- 先由 `chinese-style-guide` 检查中英文/数字空格、全半角标点、引号、日期格式；
  按检查结果加载该 skill 逐条修正；
- 修正后重跑，最后用 `markdownlint --fix` 修空行、标题包围空行、分隔线等结构
  问题，再跑 `markdownlint` 确认没有残留；
- 只改格式，不改语义、用词和段落结构。

先中文排版、后结构 lint 是有意的：中文修正可能改变行结构，markdownlint 需要
在最终文本上做最后检查。

`pdf2md.py` 默认会自动执行这一步；调参阶段可以用 `--no-lint` 提速。

导出 PDF / 电子书时不要带 YAML frontmatter：书名用 `# 书名`，作者在电子书命令
里用 `-a` 传。pandoc 默认模板会依据 YAML 再生成一个书名块，和正文里的 h1 重复。

## 按症状调参

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 章节标题变成正文 | 标题字号只比正文大一点，或全部同字号加粗 | `--heading-scale 1.05`；仍不行说明只能靠加粗/间距判断，属已知限制 |
| 小节标题被当成一级 | 字号层级多但只想保留两层 | `--heading-depth 2` |
| 每行都成了独立段落 | 该 PDF 每行都带缩进（诗歌体、台账） | 增大 `--indent-chars`，或 `--quote-indent-chars` 收进引文块 |
| 整章粘成一段 | 无首行缩进，段间距又很小 | 减小 `--paragraph-gap 0.8` |
| 段落被拦腰截断 | 段落之间有额外行距，但下一段顶格无缩进 | 增大 `--paragraph-gap 1.6` |
| 诗歌/引文与正文混在一起 | 引文缩进不足 4 字 | `--quote-indent-chars 2`（要大于 `--indent-chars`） |
| 带背景/边框的引用块变普通段落 | 样式只加了小缩进（如 1.5 字） | `--quote-indent-chars 1.4` 收进引文块 |
| 列表粘连成一段 | 行首的列表标记被 PDF 去掉 | 只能按段落处理；有 `1.`/`•` 标记时会自动还原 |
| 代码块被拆散 | 代码字体不是等宽（或扫描件） | 检查 PDF 字体；无法识别时手工加围栏 |
| 手写目录残留 | PDF 目录项没有页码，没被识别为目录 | `--skip-pages` 跳过目录页；或 `--no-toc` 后手写 |
| 页码、水印混进正文 | 不在上下 10% 区域内 | `--drop-regex '^第 \d+ 页$'`（可多次） |
| 表格变成一堆短行 | PDF 表格没有框线，`find_tables()` 找不到 | 只能人工重排；有框线时不要加 `--no-tables` |
| 图片全是整页截图 | 扫描版 PDF | 需要先 OCR；本脚本只做版面还原 |

## 脏 PDF 的处理顺序

1. `pdftotext -layout book.pdf - | head -40` 或 `--debug` + 直接看输出，
   判断是「真文本」还是「扫描图」。扫描图先 OCR（如 `ocrmypdf`），再回来跑。
2. 用 `--no-images` 快速验证文字结构，不要等图片渲染。
3. 结构对了再加图片；`--no-cover` 排除封面干扰。
4. 找出第一处错误所在的页，用 `--skip-pages` 只跑几页做快速迭代。
5. 定稿后跑全量，检查：标题数量、目录层级、首尾段落、图片张数。

## 已知限制

- **双栏 / 多栏**：按行读取会把左右栏混在一起。可先用 `mutool`/`qpdf` 裁切分栏，
  或只用 `pdftotext -layout` 取文字。脚本不做栏检测。
- **竖排**：行方向不同，`extract_text_lines()` 结果不可靠。
- **加粗标题**：仅靠字号，不看字重；所有标题同字号的 PDF 识别不出来。
- **跨页表格**：按页抽取，不合并跨页表格。
- **列表层级**：嵌套列表压平为一级，列表项之间的空行不保留。
- **代码块**：不识别语言标记；代码字体不是等宽时无法还原。
- **脚注**：会按阅读顺序混在正文里，不会自动挪到页底或文末。

## 参数速查

```text
--body-size 10.5            强制正文号（自动识别错了才用）
--heading-scale 1.12        标题阈值倍数
--heading-depth 3           标题最多几级
--heading-base 2            最大字号是几级标题（1 = 保留原 h1）
--indent-chars 2            原文首行缩进阈值（仅用于识别段落）
--quote-indent-chars 4      引文缩进阈值（字）
--paragraph-gap 1.2         段间距阈值（行高倍数）
--toc-depth 2               目录收录到第几级
--skip-pages 1-2,5          跳过页
--drop-regex RE             丢弃匹配行（可重复）
--keep-page-numbers         保留页眉页脚（排查）
--no-lint                   生成后不做 markdownlint / 中文检查
--debug                     打印统计结果
```
